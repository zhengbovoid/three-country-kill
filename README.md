# 三国杀助手（全扩展武将 · 卡牌速查 · 智能选将推荐）

零依赖、纯静态、支持离线缓存（PWA）的三国杀便携速查网页，打开链接即可在微信内置浏览器或 iPhone Safari 中使用。

**在线访问：** https://zhengbovoid.github.io/three-country-kill/

## 功能一览
- **全扩展武将速查（1,961 位官方武将 · 21 大官方扩展包）**
  - 覆盖：标准版、神话再临（风/火/林/山/阴/雷）、神将（全 75 位神势力）、界限突破、一将成名（2011–2017）、新一将（2020–2026）、谋攻篇、始计篇、门阀士族、应变·晋、兵势篇、限定史诗、SP系列、星火·活动、江山如故、群英荟萃、移动版、OL专属、四象封印、蚀心入魔、线下专属。
  - 支持魏/蜀/吴/群/神/晋六大势力筛选、按扩展包筛选、汉字/拼音首字母/技能名搜索、本地收藏及单武将直达分享链接。
- **智能选将推荐**
  - 按身份（主/忠/反/内）、本局人数、当前主公武将（支持搜索全部主公）、座位号、扩展包范围、偏好风格与操作难度智能评分。
  - 支持「候选池对比模式」：输入手头抽到的 2–6 位候选武将，直接排序并给出推荐理由与避坑提醒。
- **全扩展卡牌速查（109 种卡牌 · 7 大官方牌堆）**
  - 覆盖：标准、军争、应变篇（冰杀、出其不意、洞烛先机、逐近弃远、护心镜、乌铁锁链、五行鹤翎扇等）、用间篇（刺杀、毒、推心置腹、趁火打劫等）、国战（明光铠、太平要术、三尖两刃刀、玉玺、知己知彼、远交近攻、以逸待劳等）、逐鹿天下（草船借箭、解甲归田、树上开花等）、SP扩展，新增「宝物」分类。
- **规则与距离计算器**
  - 4–10 人身份配置、回合六阶段流程、交互式座位距离计算器与 12 条高频争议 FAQ。

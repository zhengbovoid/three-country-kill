# 三国杀助手（面杀便携速查 · 选将推荐）

零依赖、纯静态、支持离线缓存（PWA）的三国杀桌游速查网页，打开链接即可在微信内置浏览器或 iPhone Safari 中使用。

## 功能一览
- **武将速查**：收录标准版全 25 将 + 风/林/火/山 17 位经典武将（共 42 位），支持汉字/拼音首字母/技能关键词搜索、势力筛选、收藏及单武将直达分享链接。
- **智能选将推荐**：根据身份（主/忠/反/内）、人数、当前主公武将、座位号、打法风格与操作难度给出 S/A/B/C 推荐排序与理由，并支持输入手头抽到的候选武将池直接对比排序。
- **卡牌速查**：覆盖标准 + EX + 军争 36 种卡牌与高频结算争议。
- **规则与距离计算器**：4–10 人身份配置、回合六阶段流程、交互式座位距离计算器与 12 条高频争议 FAQ。

## 本地预览
```bash
python3 -m http.server 8080
```
